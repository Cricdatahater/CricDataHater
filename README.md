# Hi, I'm Samridh Goel

Statistics graduate and M.Sc. Modelling & Simulation student at Nanyang Technological University, interested in statistical modelling, stochastic simulation, machine learning, computer vision, and quantitative finance.

I build reproducible Python studies that connect mathematical assumptions to experiments, diagnostics, and real-world data. My portfolio spans calibrated computer vision, stochastic processes, Monte Carlo methods, and regime-switching volatility models.

## Selected work

- **[Calibrated EuroSAT](https://github.com/Cricdatahater/calibrated-eurosat)** — a reproducible land-cover classification study progressing from handcrafted statistical features to frozen and fine-tuned ResNet18 models, followed by temperature scaling, paired bootstrap comparisons, McNemar's test, and qualitative failure analysis.
- **[Stochastic Calculus & Monte Carlo Finance](https://github.com/Cricdatahater/Stochastic_cal_Simulation-)** — Brownian motion, Itô-calculus experiments, Black–Scholes pricing, Monte Carlo confidence intervals, and realized-volatility analysis.
- **[Regime-Switching Volatility & Option Pricing](https://github.com/Cricdatahater/Hidden_Markov_model_option_pricing-)** — frequentist and Bayesian two-state Gaussian HMM experiments with forward regime occupancy and option-price uncertainty.
